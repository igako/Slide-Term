# Slide-Term
Slides para aula introdutória de Cybersegurança da Disciplina de Informática Aplicada

Para acessar basta abrir o link: https://igako.github.io/slide-term/play
1. Pressione play
2. O simulador de terminal iniciará
3. O comando para acessar o slide é "sudo pentest"
4. Use os botões ou as setas para navegar entre as páginas
